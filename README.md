# 打工人小账本（离线单文件工作台）

一个零依赖、可离线运行的个人记账工作台：单文件 HTML，所有 CSS/JS/SVG 内联，双击即可在浏览器打开。

## 功能
- **真实时薪计算器**：综合到手月薪、发薪月数、工作成本、在场 / 通勤 / 加班时间，可展开完整公式与逐项拆解。
- **10 秒记账**：金额 + 分类 + 备注，保存后立刻换算「这笔钱 ≈ 你工作了多久」。
- **首页今日概览** + 最近 4 笔记录 + 本月速览。
- **月度总结**：本月收入、支出、结余，固定 / 弹性支出分类拆解。
- **自由基金目标 + 安全垫**：目标进度条，安全垫 = 存款 ÷ 月固定支出。
- **原生 SVG 存款曲线**：手写 SVG 折线图，无图表库。
- **情景模拟**：通勤 / 加班 / 涨薪滑块，实时重算真实时薪。
- **数据管理**：JSON 导出备份、不限条数导入恢复、一键清空示例、清空全部。

## 数据存储（重要）
- 数据**只存在你打开它的那台设备的浏览器 `localStorage`**，**不会上传到 GitHub 或任何服务器**。
- 因此：手机和电脑各自存各自的数据，**互不同步**。
- 换设备 / 清浏览器缓存前，请在点「设置 → 导出 JSON 备份」存一份；新设备用「导入恢复」即可迁移数据。

## 部署到 GitHub Pages（手机直接访问）
1. 在 GitHub 新建一个仓库（例如 `dagongren-ledger`）。
2. 把本仓库的 `index.html` 推到仓库的 `main` 分支根目录。
3. 仓库 Settings → Pages → Source 选 `main` 分支、`/ (root)`，保存。
4. 几分钟后访问 `https://<你的用户名>.github.io/<仓库名>/` 即可；手机浏览器打开后「添加到主屏幕」，体验接近 App。

### 用 Git 推送（需 GitHub 令牌 / SSH）
```bash
cd dagongren-ledger
git remote add origin https://github.com/<用户名>/<仓库名>.git
git push -u origin main
```

### 本机预览
直接用浏览器打开 `index.html` 即可，无需任何服务器。

## 更新
重新生成 `index.html` 后，覆盖并提交推送即可。GitHub Pages 通常几分钟内生效（如未更新，可在 Pages 设置里点 "Visit site" 或硬刷新 Ctrl/Cmd+Shift+R）。
